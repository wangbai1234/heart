## 三、钩子（冲突设定）写法总结

### 核心规律
1. **一句话钩子 = 冲突瞬间**（不是人设描述）：
   - "在兄长面前答应提亲后他失控了"（骨科+失控）
   - "半夜爬床认错人了"（背德+误会）
   - "抽象LOL主播被你当众包养"（反差+羞耻）
   - "一穿书就被拿剑指？我不是万人迷吗。"（穿越+落差）
   - 公式：【身份/关系】+【突发事件】+【情绪失控点】

2. **标签即卖点**（多标签堆叠精准定位受众）：
   - 关系标签：姐夫/骨科/高干/金主/娱乐圈
   - 性格标签：冷脸骚/闷骚/古板骚/回避型/引导型恋人/dom
   - 尺度标签：洁/不洁/限左/限右/背德/阴湿
   - 题材标签：仙侠古风/近代现代/穿书/娱乐圈/电竞

3. **开场即高潮**（不铺垫，直接进冲突现场）：
   - lumeow谢不逾开场直接是"答应提亲→兄长深夜闯房→给戴脚镯铃铛→'想摘下来得连皮带肉一起削'"
   - 危险+占有欲+情欲张力一次拉满

4. **爱意值/关系机制外显**："爱意值较低时他只把你当妹妹，一直想控制你也自我安慰是兄长的关心（装的很）"——把关系进展做成可感知的状态机

5. **上帝视角吐槽/元信息**：用"风闻""时辰地界在场"等结构化卡片增强世界观沉浸+提供叙事锚点

### 女性向（乙游）文案要点（结合已有 [[otome_opening_style]] 记忆）
- 第一句必须有荷尔蒙钩子/危险感
- 反糙汉：危险漏骨但不粗俗
- 强反差：人前禁欲/人后失控
- 占有欲、控制欲、禁锢感是核心爽点
