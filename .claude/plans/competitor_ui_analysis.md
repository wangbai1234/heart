## 三、钩子（冲突设定）写法总结

### 核心规律
1. **一句话钩子 = 冲突瞬间**（不是人设描述）：
   - "在兄长面前答应提亲后他失控了"（骨科+失控）
   - "半夜爬床认错人了"（背德+误会）
   - "抽象LOL主播被你当众包养"（反差+羞耻）
   - "一穿书就被拿剑指？我不是万人迷吗。"（穿越+落差）
   - 公式：【身份/关系】+【突发事件】+【情绪失控点】

2. **标签即卖点**（多标签堆叠精准定位受众）：
   - 关系标签：姐夫/骨科/高干/金主/娱乐圈
   - 性格标签：冷脸骚/闷骚/古板骚/回避型/引导型恋人/dom
   - 尺度标签：洁/不洁/限左/限右/背德/阴湿
   - 题材标签：仙侠古风/近代现代/穿书/娱乐圈/电竞

3. **开场即高潮**（不铺垫，直接进冲突现场）：
   - lumeow谢不逾开场直接是"答应提亲→兄长深夜闯房→给戴脚镯铃铛→'想摘下来得连皮带肉一起削'"
   - 危险+占有欲+情欲张力一次拉满

4. **爱意值/关系机制外显**："爱意值较低时他只把你当妹妹，一直想控制你也自我安慰是兄长的关心（装的很）"——把关系进展做成可感知的状态机

5. **上帝视角吐槽/元信息**：用"风闻""时辰地界在场"等结构化卡片增强世界观沉浸+提供叙事锚点

### 女性向（乙游）文案要点（结合已有 [[otome_opening_style]] 记忆）
- 第一句必须有荷尔蒙钩子/危险感
- 反糙汉：危险漏骨但不粗俗
- 强反差：人前禁欲/人后失控
- 占有欲、控制欲、禁锢感是核心爽点

## 第二轮调研（2026-08-10）：8 nimoo + 1 lumeow 新模板

目的：扩充可复用版式库，重点拆解「钩子内容」结构。以下每个都是 nimoo 真实角色详情页 iframe 版式。

### 模板 A｜段川柏 · 穿书系统卡
- 版式：顶部「系统提示」弹窗风（你穿进书里，绑定攻略对象）+ 任务面板（当前进度条/好感度）+ 剧情节点列表
- 钩子：元叙事——「你是读者，他是你追的书里的病态男主，现在他发现你能预知剧情」。反差=掌控感 vs 失控
- 可复用给：穿书/系统流/预知梗角色

### 模板 B｜贺禹舟 · WHISPER 会员卡
- 版式：高端私人俱乐部黑金会员卡（卡号/等级/专属权益）+ 会员条款 + 「仅限一位会员」印章
- 钩子：稀缺感——「全城名流挤破头的会所，他只给你发了唯一一张终身卡」。占有欲包装成特权
- 可复用给：金主/俱乐部/DOM/贵圈角色

### 模板 C｜陆铮 · 手机 OS + 特工档案
- 版式：仿手机锁屏/桌面（未接来电 99+/加密短信/定位）+ 解密后的机密特工 DOSSIER（代号/任务/伤疤）
- 钩子：双重身份——「他手机里你的备注是加密的，因为你是他唯一不能曝光的软肋」。危险职业 vs 独宠
- 可复用给：特工/军人/黑客/双面身份角色

### 模板 D｜周时 · 小县城 + 微信群聊
- 版式：仿微信群聊记录（家族群/发小群七嘴八舌）+ 朋友圈九宫格 + 小城烟火气便签
- 钩子：市井真实感——「全村都在给你俩牵线，他嘴上嫌弃，深夜却给你发'到家没'」。土味 vs 心动
- 可复用给：青梅竹马/小城/发小/糙汉深情角色

### 模板 E｜霍淮山 · 民国报纸头版
- 版式：泛黄报纸 DAILY NEWS 报头 + 竖排民国字 + 折叠 section（简介/成长/性格/事件/关系）+ 老照片
- 钩子：年代宿命感——「军阀/世家少爷，报上登着他的婚讯，新娘却不是你」。时代洪流 vs 逆命而爱
- 可复用给：民国/年代文/军阀/世家角色

### 模板 F｜只摘明月 · 修仙群像卷轴
- 版式：水墨卷轴纵向展开 + 多角色印章（师尊/师兄/魔君）+ 仙门关系网 + 诗词式旁白
- 钩子：群像可选——「一入仙门，师尊清冷、师兄妒忌、魔君垂涎，你选谁」。多线暧昧
- 可复用给：仙侠/群像/多攻略线角色

### 模板 G｜印尘斯 · TARGET FILE 狙击档案
- 版式：军事/狙击手瞄准镜 UI（TARGET LOCKED/坐标/心率监测）+ 猎物档案 + 血色数据条
- 钩子：猎物感——「他是杀手，接到的任务是杀你，扣扳机前却在你脸上停了三秒」。杀意 vs 心动
- 可复用给：杀手/狙击/黑帮/危险占有角色

### 模板 H｜lumeow 刘瑭 · 直播弹幕 + 故事选择
- 版式：直播间弹幕流 + 三个「故事选择」卡（每卡=标题+标签+一句钩子+放映室/开始聊天）+ 热门评论区
- 钩子：抽象搞笑反差——「抽象 LOL 主播被你当众包养，嘴硬心软」。**「故事选择」= 我们 starterBranches 的直系参照**：每分支一个情境标题+标签+一句话冲突钩子
- 可复用给：主播/电竞/搞笑/多开场分支角色

### 钩子内容公式（本轮提炼强化）
1. **身份反差**：人前一个极端，人后为你另一个极端（禁欲↔失控、冷面↔黏人、忠仆↔僭越）
2. **稀缺独占**：全世界求而不得的东西，他只给你一个人（唯一会员卡/唯一不杀的目标/唯一想住的房）
3. **失控瞬间**：他掌控一切，却唯独在你面前算不明白/扣不下扳机/说不出拒绝
4. **卑微渴望**：越强大/越危险的角色，越藏着一句不敢说的「你别走」「以别的身份留下」
