# 日本・韩国收费评估（2026-10-08）

本文件只分析，不更改收费、开通支付或承诺支付渠道批准。结论：现有“免费币 + 会员 + 模型分档”有可用基础，但不能直接把国内价格换成日元/韩元上市。尤其不建议把当前 immersive 对所有文本模型免扣币的配置当成无条件无限服务售卖。

## 代码中的实际规则

核对来源：`heart/core/config.py`、`heart/infra/model_catalog.py`、`heart/api/routes_credits.py`、`heart/membership/`、`heart/billing/checkin.py`。以下是代码默认值，实际生产环境可覆盖，不能据此认定线上订单价格。

| 项目 | 默认值 | 市场影响 |
| --- | --- | --- |
| 注册赠币 | 40 币 | 足够短体验，但需要说明每次完整回复的消耗 |
| 普通每日赠币 | 20 币，领取后永久保留 | 适合先体验后付费，签到步骤增加负担 |
| Plus / immersive 每日赠币 | 80 币 | 易解释，但用户更关心可聊多少次 |
| 文本模型 | 0.5–3 币 | 每日普通额度约 6–40 次模型回复，取决于扣费单位与模型；不应承诺固定轮数 |
| Plus / immersive 月价 | 29 / 69，源自国内价格体系 | 不应未经成本核算直接作为美元或按汇率搬运 |
| immersive | `all_llm` 等免扣币 | 高价模型重度用户可造成负毛利；必须先定义公平使用范围 |
| 语音通话 | 20 币/分钟，免费分钟 0/10/60 | 单独消耗快，开始前必须可预见成本 |
| 每日重置 | 当前按 UTC+8 | 日本/韩国 UTC+9，东南亚有多个时区；上市前在页面显示统一重置时间 |

国际模式当前关闭结账。旧生产的爱发电资格门控不作为海外商业模式。是否收费不影响安全限制，不应出售“绕过安全审核”的权限。

## 用户是否会买单

存在付费可能，不能根据竞品有付费就断言yuoyuo转化率。Zeta 的公开模式是免费入口配合高级能力消耗 Pieces；它证明市场存在这种产品形态，并不证明新产品也能获得同样的留存或价格接受度。

日本首要验证：角色语感、持续人设、关系推进、记忆准确与修正；韩国首要验证：作品发现效率、作者与题材搜索、回复速度、剧情表现。两地都应测试短/长回复的实际偏好，避免以国籍推断每个人的消费习惯。东南亚不能视为单一价格区间，应先分国家观察支付成功率、购买力与模型成本。

当前优势是可编辑的长期记忆与关系系统；它需要在免费体验阶段被用户看到，才能解释订阅价值。角色数和模型名称本身不足以形成订阅理由。

## 推荐的后续收费实验（尚未实施）

1. 保留免费体验与明示额度。优先自动发放每日额度，测试首次角色对话完成率。
2. 一个基础订阅：每日额度、合理上下文、可选语音福利。一个点数包：高价模型、额外语音等成本明显的能力。暂不增加第三层会员。
3. 高级模型按成功的完整生成计价。把失败、重试、截断、气泡拆分的收费规则明确展示并验证，不让多气泡变成不可预见账单。
4. “无限”改为可核查的公平使用额度或限速机制后才销售，写清涵盖的模型、上下文、语音与每日限制。不得先宣传无限、再隐蔽限制。
5. 日元与韩元显示本地最终应付价格，列明税费、续费和解约。价格先通过日本/韩国分别访谈与小样本试购验证，不伪造本地货币账户资格。

## 上线前单位经济模型

每活跃用户每日成本 = 主回复输入/输出 + 记忆抽取/摘要/向量 + 开场生成 + 重试与备用模型 + 语音 + 存储带宽 + 支付费用与退款损耗。

每订阅净收入 = 收款额 − 税与渠道费 − 退款拒付 − 该用户月度服务成本。按 P50/P90/P99 活跃用户核算，不能只看平均值；没有供应商实际账单时不能声称利润率。

建议监测（都是实验指标，不是预测）：首次对话完成率、D1/D7留存、每次成功回复成本、记忆纠错率、充值页面到支付成功转化、订阅次月续费、退款/拒付、免费与付费用户P90成本。先稳定体验，再决定JPY/KRW价点和预算上限。
