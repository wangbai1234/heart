# 同语言完整上下文：角色与真实 Gemini 验收

日期：2026-10-13。只在本地修改和验证，没有推送或生产部署。

## 用户本轮验收标准

英语指令＋英语人设/开场/上下文＋英语提问；越南语和孟加拉语同理。跨语言输入不属于本轮测试，也不使用上一轮中文输入测试判定本轮失败。

## 实现与范围

- 延续分语种提示词目录，移除 en/vi/bn 主生成提示里的英文 OUTPUT LANGUAGE 固定句。
- 补齐角色生成器自动注入的性别、年龄、背景标题、说话模式，以及五种默认心理模板中进入聊天提示的全部字段。
- 动态情绪摘要和心境按回复语言生成；情绪字典与关系阶段枚举均有三语资源。修复将表达指南字典的英文键直接串进提示词的问题，改为按结构化数值输出原生语言说明。支持实际关系状态的大写枚举。
- 同语言的角色说话示例允许进入提示。语言不同的旧例句不混入。
- 同语言作者开场白直接播放、落库并作为后续对话历史，不再额外调用模型重译。确需生成/适配开场时，也使用目标语言任务指令，并正确选择 vi/bn 名称及完整角色人设。
- 原始角色/记忆数据不做文本替换；全套同语言的前提是选择对应语言版本的角色。本轮没有宣称原有 222 个中文角色已全部翻译，也没有用旧中文历史进行验收。
- 未来批次需要把译稿按目标 locale 重建 SoulSpec，才能得到本轮修正后的默认字段；仅修改 UI 语言不能翻译原始角色数据。

## 测试角色

来源是首发名单中的苏晚（su_wan，25 岁花店店主）和许知寒（xu_zhihan，20 岁数学系学生）。各制作 en/vi/bn 三个测试副本，译有人设、背景、开场白、名称、身份标签和展示短句；测试简介从译文摘要，不代表整批发布审校。

六份可复用样本保存在 `backend/tests/fixtures/monolingual_characters.json`。canonical 标签和媒体标识保留，它们没有进入模型消息。原始记录没有被覆盖。测试账号和历史独立于真实用户；测试结束后副本已停用。

## 完整请求核验

先通过真实 HTTP/WS/PostgreSQL 路径、fake 响应完成 6 份请求预检，再进行真实调用。使用本地专用入口，在 ModelRouter 接收消息时检查并保存本轮测试角色的原始 messages；审计代码位于活动仓库外，测试后恢复正常应用入口。

- 六份最终消息均无汉字，含同语言开场历史及本轮同语言提问。
- 孟加拉语消息正文无拉丁字母；仅协议分隔标记 `<<<USER_MESSAGE>>>` / `<<</USER_MESSAGE>>>` 保留原样。角色/消息 role 等机器字段和动作括号仍按接口协议保留。
- 检查的是所有发送消息，不只 system 末尾。完整请求与 SHA-256 在本报告旁 `payload-*.json`，仅含本次测试资料。
- 预检曾发现英文 relief 和 STRANGER，均在付费调用前修复。首次开场测试因测试脚本把 query 参数放进 body 而 422，也已修正；这些不计入真实模型请求。

## 真实 API：每种语言两次

| 语言 | 苏晚 | 许知寒 |
|---|---|---|
| 英语 | Gemini 返回英语，已落库 | 请求失败，无回复 |
| 越南语 | Gemini 返回越南语，已落库 | 请求失败，无回复 |
| 孟加拉语 | 请求失败，无回复 | Gemini 返回孟加拉语，已落库 |

合计 6 次应用请求，3 次成功；成功回复的语言符合率是 3/3，整体请求成功率是 3/6。没有中文回复，没有成功的备用模型回复。每种语言各测试两个角色的一次回复，开场白属于已有历史；不宣称验证了长对话稳定性。

请求路由均为 gemini-3.1，配置的 API 模型为 gemini-3.1-flash-lite-preview；成功结果的 served_model 均为 gemini-3.1。该元数据证明应用使用的通道，不能独立证明中转商内部模型。

失败日志：苏晚孟加拉语、许知寒越南语的 Gemini 超过现有 6 秒首 token 门槛，随后备用通道失败；许知寒英语 Gemini 通道失败，备用通道首 token 超时。仍可见上游 HTTP 错误和流式异常读取问题。没有改全局超时、默认模型或安全边界来让结果变绿。

本轮真实轮次用时合计 47.57 秒。脚本无重试；应用内置 fallback 会产生额外上游尝试。角色样本翻译没有另外调用付费 API，开场白也没有调用生成 API。真实调用金额无法从流式记录可靠取得，以服务商账单为准。

## 工程验证

- 完整 CI：2083 passed, 34 skipped, 57 warnings in 156.44s (0:02:36) ===========；84 前端测试、lint/schema/build 通过。
- 国际化/批次 fake E2E 14 通过；暂停国际化 E2E 3 通过；六份实际消息预检 6 通过。
- 新增 35 项单测覆盖五种默认风格 × 六份角色、完整提示语言、所有已配置情绪/关系枚举、同语言开场零模型调用及跨语言开场指令。
- 现有封面单行标签修改保留；本轮没有 UI 布局修改。

## 结论

按用户要求的同语言链路，Gemini 已分别成功返回英语、越南语、孟加拉语。当前证据支持采用“目标语言提示词＋对应语言角色版本＋同语言上下文”的方案。三次无回复属于独立的请求稳定性问题，不能计作语言回答错误，也不能忽略后宣称六次全通过。生产发布仍需完成整批角色翻译和 API 通道稳定性处理。
