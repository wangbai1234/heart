# 角色页响应式比例修复（2026-10-13，本地验收）

## 问题与修复

浏览器恢复 100% 后仍拥挤，根因是布局的宽度预算与卡片文字高度，没有按实际内容容器处理。

- 旧国际版电脑壳按窗口高度计算宽度，1366×768 下只剩 343.25px。现桌面内容宽度为 `min(430px, 100% - 24px)`，高度仍跟随窗口，页面内部继续滚动。
- 320px 手机下旧顶部控件最右端到 398px，部分功能被裁切。现角色页使用紧凑语言标识，原生下拉仍列出完整语言名；小屏 Logo、间距与搜索输入按实际内容宽度调整。
- 旧 320px 卡片文字区域高 123.25px、封面高 193.05px，占约 64%。现以卡片容器宽度决定字号与简介行数：名称一行，窄卡片简介一行、宽卡片最多两行；统计和两个标签固定分行，两个标签同行。
- 底部导航使用等宽栏位，文字保持单行，过长时省略，完整文案保留在可访问名称和标题中。
- 明确设置 `text-size-adjust: 100%`，防止手机浏览器自动放大文本；保留浏览器缩放和应用字号偏好。

本次保持原双列竖版封面、配色、功能入口和语言角色优先排序；没有修改角色内容、数据库或生产配置。
