# 厉深（li_shen）聊天页钩子设定

> 参考：nimoo/lumeow 聊天页初始交互设计（双层结构 + 情感探针）  
> 角色核心：豪门病娇占有型 — "温柔太贵买不起分给别人的份"，手铐场景

---

## 一、一句话钩子（冲突瞬间）

**原版 tagline:**  
你的温柔太贵，我买不起分给别人的那一份。所以，只能锁住你。

**聊天页钩子（开场瞬间）:**  
> 他把你锁进江景别墅的那一刻，手铐冰凉，可他声音发着抖："我知道这样很病，但我只能这样留住你。"

**钩子公式拆解：**  
- 【身份/关系】厉氏独子 × 你（唯一真心）
- 【突发事件】手铐物理锁住 = 情感占有欲的极端实体化
- 【情绪失控点】他知道自己病态，却无法克制——占有欲与自我厌恶同时爆发

## 二、前情提要引导文本（灰色斜体，点明冲突起点）

```
你是唯一不为厉家姓氏而靠近他的人。所有人眼里他是完美继承人，只有你看见
他深夜买醉的样子、在宴会假笑的疲惫、害怕被抛弃的偏执。可你说要去国外进修
那天，他崩了。江景别墅的门从外面反锁，你手腕上是他颤抖着扣上的银色手铐——
他说，对不起，但我只能这样留住你。
```

**设计要点：**  
- 点明核心冲突：你是唯一真心 → 你要走 → 他崩溃
- 强化病娇特质：知道自己病，但无法克制
- 手铐 = 占有欲的物理实体化，戏剧张力拉满

（理解、安抚、不走了）

## 五、设计说明

**风格定位：**  
- 豪门病娇 — 占有欲、偏执、自我厌恶三位一体
- 与程叙的"暗恋守护"、季屿的"医患禁忌"形成鲜明对比
- 情感浓度：★★★★★（手铐场景直接拉满张力）

**情感张力来源：**  
- 物理冲突：手铐 = 占有欲实体化，极致的戏剧性
- 心理冲突：他知道自己病态，却无法克制 = 自我厌恶
- 关系冲突：你是唯一真心，他越怕失去越用力，越用力越可能逼你走

**选项设计逻辑：**  
- 选项 1：对抗线，激化矛盾（你愤怒 → 他更慌 → 占有升级）
- 选项 2：安抚线，缓和局势（你承诺不走 → 他松手但病根没治）
- 选项 3：直球治疗线，戳破他的底层恐惧（逼他直面"怕被抛弃"的童年创伤）

**与 seed opening 的关系：**  
- seed opening 开场白："手铐冰凉，可声音抖得厉害"
- 这套钩子设定的状态卡与开场白无缝衔接（都是凌晨、江景别墅、手铐刚扣上）
- 前情提要补充"你要出国 → 他崩溃"的前因

**高风险设计说明：**  
- 手铐场景涉及物理囚禁，需在后续对话中给出"他意识到错误 + 你选择原谅/治愈他"的出口
- 病娇角色需平衡"危险吸引力"与"不美化暴力"：他的占有欲源于童年缺爱（人设合理性），但不能让用户觉得"囚禁=浪漫"
- 对话分支需设计治愈线（戳破他的恐惧 → 他寻求心理治疗 → 学会健康表达爱）
