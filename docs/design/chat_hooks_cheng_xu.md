# 程叙（cheng_xu）聊天页钩子设定

> 参考：nimoo/lumeow 聊天页初始交互设计（双层结构 + 情感探针）  
> 角色核心：暗恋守护型 — "替你哥照顾你"是名义，真实心动藏进日常

---

## 一、一句话钩子（冲突瞬间）

**原版 tagline:**  
你哥让我照顾你。可有些好，早就不只是替他给的了。

**聊天页钩子（开场瞬间）:**  
> 初雪街角他替你系围巾的手停了三秒，你没发现——可你哥的未接来电，他看见了。

**钩子公式拆解：**  
- 【身份/关系】哥哥的朋友，被托付照顾你
- 【突发事件】暗恋日常与朋友名分的碰撞瞬间（系围巾 vs 你哥来电）
- 【情绪失控点】他在"该不该越界"里挣扎，而你浑然不觉

---

## 二、前情提要引导文本（灰色斜体，点明冲突起点）

```
初雪的傍晚，他准时出现在你必经的路口。热腾腾的糖炒栗子、刚好扣紧的围巾、
连你室友那点麻烦他都处理妥当——这份无微不至，你一直以为是因为你哥的托付。
可你没看见，他把手机扣进口袋的那一刻，屏幕上跳着你哥的未接来电。
```

**设计要点：**  
- 点明日常守护场景（糖炒栗子、围巾、处理麻烦）
- 埋钩子：你以为是朋友义务，实则他在越界边缘挣扎
- 冲突张力：你哥来电 = 名分与心动的撞击

**守护日志 · DAY 247**（象征他照顾你的第 247 天，每一天都记得）

| 字段 | 内容 |

## 四、情感探针式引导选项（3 个切入角度 + 每角度 2-3 条台词）

### 引导语（灰色小字）
你会怎么回应他

### 选项设计

#### 1. **当他只是哥哥的朋友**
（保持名分，接受他的照顾但不越界）

- 程哥，谢谢你一直照顾我
- 有你在，我在这座城市不孤单
- 等我哥回来，我一定跟他说你对我多好

#### 2. **试探那份心动**
（主动靠近，确认他的心意）

- 你手机一直在响，是不是我哥打的
- 你这么照顾我，真的只是因为我哥吗
- 你刚才系围巾的时候，耳朵红了

#### 3. **越过朋友的界线**
（直球表白/打破暧昧）

- 我不想你只是"哥哥的朋友"
- 那些照片，我看到了
- 我也喜欢你，从很久之前

## 五、设计说明

**风格定位：**  
- 治愈系暗恋 — 温柔、克制、日常感强
- 与季屿的"医患禁忌"、厉深的"豪门占有"形成差异化

**情感张力来源：**  
- 他守护你是真心，但名义是"替你哥"
- 你若主动，他会慌、会红耳朵、会在"该不该"里挣扎
- 双向奔赴的前夜——你先越界，他才敢接住

**选项设计逻辑：**  
- 选项 1：维持现状，他继续暗恋守护
- 选项 2：试探阶段，戳破暧昧但不表白
- 选项 3：直球推进，打破朋友界限

**与 seed opening 的关系：**  
- seed opening 是开场白文本（AI 第一条长消息）
- 这套钩子设定是**开场白之前**的前情提要卡 + 开场白之后的引导选项
- 状态卡的"围巾系到一半 + 你哥未接来电"呼应 opening 里的"手机被他不动声色地扣进了口袋"
